# LMX Sync — сервер (Cloudflare Workers + D1)

Безкоштовний тариф Cloudflare вистачає з великим запасом для кількох десятків користувачів.

## Розгортання без командного рядка (через сайт Cloudflare)

1. Зареєструйтесь на https://dash.cloudflare.com (безкоштовно).
2. **Storage & Databases → D1 SQL database → Create**. Назва: `lmx-sync`. Створіть.
3. Відкрийте створену базу → вкладка **Console** → вставте вміст файлу `schema.sql` → **Execute**.
4. **Workers & Pages → Create → Create Worker**. Назва: `lmx-sync` → **Deploy** → **Edit code**.
   Видаліть увесь код у редакторі, вставте вміст `worker.js` → **Deploy**.
5. У цьому ж Worker: **Settings → Bindings → Add → D1 database**. Variable name: `DB`, база `lmx-sync` → **Deploy**.
6. (Необов'язково, прибирання старих даних) **Settings → Triggers → Cron Triggers → Add**: `17 3 * * *`.
7. Адреса Worker: `https://lmx-sync.<ваш-піддомен>.workers.dev`. Перевірка: відкрийте її в браузері — має з'явитись `{"ok":1,"service":"lmx-sync"}`.
8. Підставте адресу в `lmx_sync.js` у рядок `var DEFAULT_SERVER = '...'` (або кожен користувач вводить її в Налаштування → LMX Sync → «Адреса сервера»).

## Як це працює
- Користувач сам створює код у плагіні; сервер бачить лише SHA-256 від коду.
- Запис = ключ (`f:<список>:<id>` або `t:<хеш>`) + JSON + час зміни. Перемагає пізніший час. Видалення — запис-«надгробок».
- Обмеження: 500 записів за запит, 12 000 записів на користувача, 1 МБ на запит, час зміни не може бути далі ніж на 5 хв у майбутньому.
- Дані не зашифровані: власник сервера може їх прочитати. Збереження чужих даних — ваша відповідальність.
